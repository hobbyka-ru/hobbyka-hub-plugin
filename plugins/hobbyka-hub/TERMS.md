# Условия использования Hobbyka Hub

Hobbyka Hub предназначен для сотрудников Хоббики и работает с корпоративным каталогом плагинов через VPN.

Установка и обновление меняют только управляемый marketplace Codex текущего пользователя. Публикация, отправка предложения, ошибки или идеи выполняются только по соответствующей явной команде и её подтверждению.

Пользователь отвечает за выбор отправляемых исходников и вложений. В плагин нельзя включать секреты, чужие персональные данные или материалы без права использования.
